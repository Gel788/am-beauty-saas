# Am Beauty design system

The mockups in `docs/design/` are the source of truth for UI: the PNGs (`dashboard.png`, `calendar.png`, `booking.png`) and the original HTML in `docs/design/src/` (`dashboard.html`, `calendar.html`, `booking.html`, generated by `build.py`). Port from that HTML. Do not redraw by eye.

Rule: **port from mockups HTML, verify with visual-compare, diff must not regress.**

Before finishing any UI task, run `npm run visual:check` (or `node scripts/visual-compare/compare.mjs`). It renders each mockup and the app at 1440×900, writes side-by-side PNGs to `scripts/visual-compare/out/`, and fails when a screen's pixelmatch diff exceeds `scripts/visual-compare/baseline.json` by more than 0.5 percentage points. Also confirm nothing wraps or clips at 1440×900 and 1280×800, and that Unbounded and Inter are loaded.

### Materials

- **Glass** (`.glass`): `rgba(255,255,255,.62)`, `backdrop-filter: blur(24px) saturate(160%)`, border `rgba(255,255,255,.85)`, shadow `0 1px 1px rgba(60,30,90,.03), 0 4px 10px -4px rgba(60,30,90,.06), 0 24px 48px -24px rgba(90,40,140,.18)`.
- **Solid** (`.solid`): `#fff`, border `#F1EAE6`, shadow `0 1px 2px rgba(60,30,90,.04), 0 12px 32px -16px rgba(90,40,140,.16)`.
- **Gradient** (`.grad`): `linear-gradient(120deg, #7C3AED 0%, #C026D3 55%, #F472B6 100%)`.
- **Gradient text** (`.gradtext`): `linear-gradient(100deg, #6D28D9, #DB2777 60%, #F97316)` clipped to text.
- **CTA shadow** (`.cta`): `0 14px 30px -10px rgba(192,38,211,.55), inset 0 1px 0 rgba(255,255,255,.35)`.
- **AI orb** (`.orb`): radial `circle at 32% 28%` from `#fff` through `#FBCFE8`, `#E879F9`, `#A855F7`, `#6D28D9` to `#4C1D95`, with the inset and magenta glow from the mockup.
- **Monogram** (`.mono`): `linear-gradient(145deg, #2A1B3D, #1A1523)`. The "Am" glyph uses `linear-gradient(100deg, #E9D5FF, #F9A8D4 50%, #FDBA74)` clipped to text.
- **Aurora**: four blurred blobs — `#DDD0FF` 520×520 top-left, `#FFD3E6` 480×480 top-right, `#FFE1C7` 520×420 bottom-right, `#E9DDFF` 360×360 bottom-left. Blur 70px.
- **Grain** (`.grain`): fractal-noise SVG tile, opacity `.07`, `mix-blend-mode: multiply`, above the UI, `pointer-events: none`.

### Type and icons

- Page titles use Unbounded. Body, nav, and meta use Inter.
- Icons are Lucide, 18×18, stroke 1.8 (`.ic`).
- Positive deltas are `bg-emerald-100 text-emerald-700`. Primary actions on dark ink are `#1A1523` with white text. The journal "Запись" button is `.grad.cta`.
