# 14 · Приложение на телефон (PWA)

## PWA-INSTALL-01 · Приложение для сотрудников
- `/manifest.webmanifest`: «Am Beauty», иконки 192/512 и maskable, `display: standalone`, ярлыки «Журнал», «Мой день», «Клиенты».
- Запуск открывает `/journal?app=1`; мастер сразу попадает в «Мой день».
- В боковом меню кнопка «Установить приложение», если браузер предлагает установку. На iPhone вместо неё подсказка: «Поделиться» → «На экран „Домой“».

## PWA-INSTALL-02 · Запись для клиента
- У страницы онлайн-записи свой манифест `/b/<салон>/<филиал>/manifest.webmanifest` с названием филиала и цветом страницы записи.
- Клиент добавляет запись на экран «Домой»; приложение открывается сразу на записи с меткой канала `src=app`.

## PWA-OFFLINE-01 · Без сети
- Service worker `/sw.js`. Данные (`/api/*`) не кэшируются никогда: деньги, расписание и персональные данные только живые.
- Кэшируются файлы сборки с хешем в имени и иконки. Страница записи клиента сохраняется после первого открытия.
- Без сети открывается `/offline.html`: объясняет, что журнал и касса работают только онлайн, и сама перезагружается, когда сеть вернётся.
- На localhost кэш выключен, чтобы не мешать разработке.

## PWA-PUSH-01 · Уведомления на телефон
- Кнопка «Уведомления на телефон» в меню: браузер спрашивает разрешение, устройство подписывается, приходит проверочное уведомление.
- Всё, что попадает в «Уведомления» (`notifyDesk`: новая онлайн-запись, отмена, подтверждение, просьба отменить), приходит пушем владельцу и администраторам филиала, а также мастеру этой записи.
- Нажатие открывает запись в журнале (`/journal?open=<id>`).
- Устройство, которое браузер больше не принимает (404/410), удаляется. Повторное нажатие кнопки выключает уведомления на этом устройстве.
- Ключи VAPID: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` в окружении. Без них приложение создаёт пару само и хранит закрытый ключ зашифрованным `INTEGRATIONS_KEY`.
- API: `GET /api/push`, `POST /api/push/subscribe`, `POST /api/push/unsubscribe`, `POST /api/push/test`.

## PWA-MOBILE-01 · Журнал на узком экране
- Шапка и переключатели переносятся, показатели листаются вбок, сетка журнала прокручивается в обе стороны, у колонки мастера не меньше 140 px. AI-панель на телефоне скрыта.
